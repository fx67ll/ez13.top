# ez13.top

[**fx67ll's Online Clock**](https://ez13.top)

简洁、安静、专注的北京时间在线时钟站点，基于 `EMMMS` 基座架构与 `fx67llVueUI` 组件库重构而来，采用沉浸式极简设计。

## 功能特性

* **沉浸式首屏**：默认全屏居中展示时钟，页面仅保留时钟、左下角快捷键小字提示与合规页脚，无任何多余元素
* **快捷键配置模式**：`Ctrl+E+Z`（三键同按，兼容 `Mac` 的 `Cmd`）唤起悬浮设置面板，再次按下或 `Esc` 返回沉浸模式，面板悬浮显示不挤占页面布局；左下角快捷键小字为隐藏入口，悬浮点亮后点击亦可直达设置面板
* **三种时钟风格**：数字时钟（模拟指针钟盘 + 数字时间 + 日期星期）、二进制时钟、翻页时钟（`flipclock`），面板内一键切换
* **丰富的本地配置**：时钟类型、主题（`fx67ll` 等 7 套）、12 小时制、秒针扫动样式、显示内容组合、翻页倒计时目标时间、缩放尺寸（0.6 - 2.4）等均可自定义
* **时间来源可切换**：三种时钟默认本机时间优先、偏差超过 1 秒时按网络时间静默校正；网络校时请求附加随机参数绕开缓存，修复生产环境初始化时间跳变问题；设置面板通用区可一键切换「同步本地时间 / 同步网络时间」并查看最近一次校时结果
* **永久配置缓存**：配置自动持久化到 `localStorage`，永久生效，直至手动清除浏览器数据或点击「恢复默认」，历史遗留非法配置自动回退默认值
* **缩放保持居中**：时钟无论缩放到多大始终在视口正中，超出部分四周均匀裁剪
* **404 路由拦截**：首页不再渲染 404 页面，同时保留任意未知地址的 404 拦截能力
* **合规页脚**：全站底部统一使用 `fx67ll-footer` 组件

## 技术栈

* `Vue 2` + `Vue CLI 3` + `vue-router（history 模式）` + `Vuex` + `ElementUI` + `Less` + `core-js 3`
* 基于 `EMMMS` 项目架构重构，移除 `origin` 页面及相关逻辑、`three` / `underscore` / `axios` 等无用依赖
* 时钟组件来自 [`fx67ll-vue-ui`](https://github.com/fx67ll/fx67llVueUI)（0.7.1 及以上版本），翻页时钟基于 [`flipclock`](https://www.npmjs.com/package/flipclock)

## 项目结构

```
├── public                  # 静态资源与站点图标
├── src
│   ├── assets/styles       # 全局样式（mixin.less / 404.less）
│   ├── components          # 本地组件（FlipClock 翻页时钟封装）
│   ├── router              # 路由（首页 / 404 / 通配拦截）
│   ├── store               # Vuex 骨架
│   ├── utils               # 本地界面配置工具（localConfig.js）
│   └── views               # 页面（Home 沉浸式首页 / 404）
├── web.config              # IIS 配置（HTTPS 301 强制跳转 + history 路由回退）
└── baidu_verify_*.html     # 百度站点验证文件
```

## 使用

```bash
# 安装依赖（需要 npm 上已存在 fx67ll-vue-ui 0.7.1 及以上版本）
npm install

# 本地开发
npm run serve

# 生产构建，产物输出至 dist 目录，部署 IIS 时连同 web.config 一起发布
npm run build
```

## 版本历史

## 0.1.1.20260819
* 修复线上初始化时间与本地时间不符的问题：数字时钟的网络校时 `HEAD` 请求改为附加随机查询参数的全新地址（每次同步完成后轮换），避免生产环境响应头无 `Cache-Control`、走启发式缓存时命中缓存拿到过期的 `Date` 响应头，导致时钟按缓存年龄跳变
* 新增全局「时间来源」配置（`timeSource`，默认 `auto`）：`auto` 为本机时间优先、偏差超过 1 秒按网络时间静默校正，`local` 为完全使用本机时间，随 `localStorage` 持久化并纳入枚举白名单校验，对三种时钟统一生效（历史版本存于 `digital.timeSource` 的取值自动迁移）
* 时间同步升级为各时钟通用能力：共享校时引擎（周期 5 分钟 + 页面恢复可见时补偿 + 手动触发）统一测量网络偏差，数字时钟经组件内部同步、翻页时钟以偏移基准起跳、二进制时钟注入偏移取时，全部跟随「时间来源」切换；设置面板通用区新增「时间同步」行：「同步本地时间」一键切回本机电脑时间，「同步网络时间」立即发起一次全新网络校时，并实时展示最近一次校时结果（一致 / 校正时长与方向 / 失败）
* 左下角 `Ctrl+E+Z` 快捷键小字升级为隐藏入口：悬浮时指针变手型、圆点呼吸闪烁、文字点亮上浮并扫出下划线，点击直达设置面板

## 0.1.0.20260815
* 基于 `EMMMS` 基座架构重构整站，清空原静态站点全部文件（保留 favicon 与百度站点验证文件）
* 移除 `EMMMS` 中 `origin` 页面与相关路由逻辑、`three` / `underscore` / `axios` 等无用依赖，`core-js` 由 2.x 升级至 3.x
* 首页不再渲染 404 页面，通配路由改为重定向至专用 `/404` 路由，保留 404 拦截能力
* 引入 `fx67llVueUI` 0.7.1 的数字时钟（默认 `fx67ll` 主题）与二进制时钟组件，引入 `flipclock` 翻页时钟作为第三种显示风格，支持时钟与倒计时两种模式
* 采用沉浸式极简设计：默认全屏居中展示时钟，`Ctrl+E+Z` 唤起悬浮设置面板，再次按下或 `Esc` 返回沉浸模式
* 新增本地界面配置：默认设置加载、本地修改、枚举白名单与数值范围校验、持久化到 `localStorage` 永久生效、恢复默认，历史遗留非法配置自动回退
* 页面底部统一使用 `fx67ll-footer` 组件确保合规
